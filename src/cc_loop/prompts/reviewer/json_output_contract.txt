## Stable JSON Output Contract
Respond with JSON only using this exact shape:
{
  "decision": "approve",
  "reason": "Why this attempt is acceptable or not",
  "issues": [],
  "retry_prompt": "",
  "stop_reason": "",
  "inspected_artifacts": [],
  "inspected_files": [],
  "test_status_checked": true
}
Allowed decisions: "approve", "reject", "stop", "replan".
For "approve", keep issues empty and retry_prompt empty.
For "reject", include concise issues and a retry_prompt the implementer can execute.
For "stop", include stop_reason.
For "replan", include replan_reason and replan_prompt or suggested_changes.
Set inspected_artifacts to artifact paths you reviewed.
Set inspected_files to changed file paths you verified.
Set test_status_checked true only after reading test status/output evidence.
